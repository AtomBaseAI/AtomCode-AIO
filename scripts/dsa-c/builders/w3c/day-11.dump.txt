    int top = 0;
    for (int i = 0; s[i]; i++) {

It must fill out[i] with the first arr[j] such that j > i and arr[j] > arr[i]; use -1 when no greater element exists. The harness prints the out array. A single left-to-right pass with a stack solves this in O(n).

    for (int i = 0; i < n; i++) out[i] = -1;

int min_after_ops(const int *ops, int m) {

It must scan the tokens left to right, push operands, and on each operator pop b then pop a, compute a OP b, and push the result. Return the single value left on the stack. Division is integer division; b is never 0.

Input Format:
One line: a postfix expression with single-space-separated tokens.

Output Format:
One line with the evaluated value.

Constraints:
2 <= number of tokens <= 99, no division by zero
TC s1 IN<2 3 +> EXP<5>
TC s2 IN<9 2 - 3 *> EXP<21>

SRC:
int eval_postfix(const char *expr) {
    int stack[200], top = 0, i = 0;
    while (expr[i]) {
        if (expr[i] == ' ') {
            i++;
            continue;
        }
        if (expr[i] >= '0' && expr[i] <= '9') {
            stack[top++] = expr[i] - '0';
        } else {
            int b = stack[--top];
            int a = stack[--top];
            int r = 0;
            if (expr[i] == '+') r = a + b;
            else if (expr[i] == '-') r = a - b;
            else if (expr[i] == '*') r = a * b;
            else r = a / b;
            stack[top++] = r;
        }
        i++;
    }
    return stack[top - 1];
}

Output Format:
One line with the length.

Constraints:
1 <= length of s <= 999
TC s1 IN<(()> EXP<2>
TC s2 IN<)()())> EXP<4>
TC t1 IN<()(()> EXP<2>
TC t2 IN<(> EXP<0>
TC t3 IN<()(())> EXP<6>
SRC:
int longest_valid(const char *s) {
    int stack[1005], top = 0, best = 0;
    stack[top++] = -1;
    for (int i = 0; s[i]; i++) {
        if (s[i] == '(') {
            stack[top++] = i;
        } else {
            top--;
            if (top == 0) {
                stack[top++] = i;
            } else {
                int len = i - stack[top - 1];
                if (len > best) best = len;
            }
        }
    }
    return best;
}
